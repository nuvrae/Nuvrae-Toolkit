# Nuvrae Toolkit :

A collection of tools designed to make game development in Godot easier.

It brings together different systems and helpers in one plugin, giving developers useful tools without having to build everything from scratch.

The goal is simple: spend less time building the same systems over and over, and more time actually making your game.

## Features :
Animation System:
Create, organize, and play animations using a simple animation system.

- Define animations using animation data instead of writing everything manually.
- Use built-in animation operations such as moving, rotating, scaling, fading, and more.
- Play multiple animations at the same time.
- Animate different properties of the same node independently.
- Create timelines with animations that play together or one after another.
- Use looping animations and reusable animation definitions.
- Control animations through a simple set of function calls.

Audio System:
Manage your game's music and sound effects through a central audio system.

- Play and manage background music.
- Handle multiple music and sound effect channels.
- Keep audio playback organized in one place.
- Make it easier to trigger sounds from different parts of your game.

Helper Systems:
Useful tools and functions to reduce repetitive work and make common tasks easier.

- Access shared tools through simple function calls.
- Keep common systems organized instead of spreading the same code across different scripts.
- Reduce repeated code and make your projects easier to maintain.
- Build on top of the toolkit or adapt its systems to your needs.

## Installation:

1. Download or clone this repository.
2. Copy the `nuvrae_toolkit` folder into your project's `res://addons/` directory.
3. Open Godot and navigate to Project → Project Settings → Plugins.
4. Enable Nuvrae Toolkit.

Refer to the documentation and example projects for information on using the toolkit.
