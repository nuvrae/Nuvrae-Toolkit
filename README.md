# Nuvrae Toolkit :

A collection of tools and utilities for Godot Engine, designed to make development easier and more flexible.

## Features :

- Custom AnimationSystem
- Data-driven animation timelines
- Sequential and parallel animation operations
- Reusable animation presets
- Flexible animation targeting

## Installation:

1. Download or clone this repository.
2. Copy the `nuvrae_toolkit` folder into your project's `res://addons/` directory.
3. Open Godot and navigate to Project → Project Settings → Plugins.
4. Enable Nuvrae Toolkit.

## Usage

Refer to the documentation and example projects for information on using the toolkit.

## Compatibility:
Godot 4.x
